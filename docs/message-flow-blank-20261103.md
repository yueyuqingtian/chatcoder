# 消息流偶发空白修复记录

## 复现场景

进入设置再返回后，主消息流和子消息流出现大片历史空白，底部仍有新输出，上下滚动后恢复；其他面板可见性和尺寸变化也可能触发。

设置切换通过 PageTransition 卸载主消息区，右侧面板通过 visible/display 保活隐藏。本轮同时处理重建与保活，而不是只追加会话 key。

## 实现

- 适配器独占外层总高和主轴 top。移除多处 height 覆盖、JSX 的 top:item.start、内部 scrollOffset 赋值及直接删除缓存 Map；应用写入会绕过适配器的 lastSize/lastPositions 比较，导致 DOM 和模型不一致。
- 公开 measure/resizeItem 更新测量：先读齐有效高度再失效；隐藏视图的零尺寸不覆盖缓存。
- 后续修正末条底部空白：无 pendingSuggestion 时不再创建建议尾槽；可见且已布局的空项允许实测为零，只有隐藏/未布局才回退缓存。公开重测也回填零高度，防止空槽重新变为估高。
- 普通正文与过程容器不再整块二次卸载。长代码、长表格和大型工具行保留专用窗口，由同一个视口协调器处理滚动、尺寸、布局提交、重新显示和焦点事件，不依赖 IO 首次回调。
- 可见块进入不受 busy 阻止；busy 只暂停离屏清理和离屏重测。无有效几何时保留窗口，恢复时重新取得宽度、内容及字体布局。
- 恢复待办独立于 rAF 代次。任务执行前或执行中被运动取消，最后一个运动源退出后补跑；卸载后的旧闭包不执行。
- 设置返回广播一次工作区恢复事件。主动经偏移观察回调提交 scrollTop，覆盖「偏移没变、没有 scroll 事件」的场景。
- 二十个视图以内的轻量阅读位置缓存，保存跟随意图、消息锚点和偏移，不持有正文；主区重建与面板保活恢复都不强制抢走上翻阅读位置。
- 数据、尺寸和可见性纪元变化后，单次检查外层覆盖与内层窗口；同一代不重复恢复，无常驻轮询。

## 验证与边界

已通过 flow-blank 和 reconcile-budget 两个定向回归文件。覆盖首屏正文/长内容、busy 进入视口、隐藏恢复、公开缓存失效通知，以及执行前/执行中取消后的补跑、交叠运动源和卸载清理。最终类型检查、设计规范、图标注册检查及生产构建通过，git diff --check 无空白错误；构建仍有既有大 chunk 提示。未扩展压力测试。

真实 Electron 的设置往返、标签切换、面板拖拽/折叠、最小化恢复由用户后续验证；单元回归不能替代实际界面验收。本轮不修改后端协议、消息数据和版本号。

## 仍有异常时的布局快照

在当前页面开发者工具 Console 执行：

```js
window.__chatcoderFlowDiagnostics?.()
```

返回 recent（最多十六条恢复记录）和 current（调用时的各消息流布局）。包含视图标识、尺寸、DOM 与模型偏移、虚拟范围和挂载数量，不含正文。`unresolved` 表示同一代恢复后仍无内容覆盖，会记录一次警告，不反复重测。即使只有部分历史空白、底部仍有输出，也能通过 current 取得现场；建议先读取再滚动。
